#Lloc Web de Motos KTM

## 📋 Descripció del Projecte

Aquest projecte consisteix en un lloc web  dedicat a les motos KTM. El lloc consta de dues pàgines principals que mostren diferents models de motos KTM.

### 🎯 Característiques Principals

- **Disseny modern** amb paleta de colors taronja i negre
- **Totalment responsive** per a tots els dispositius
- **Efectes d'animació** en imatges i botons
- **Navegació intuïtiva** entre pàgines
- **Estructura organitzada** i codi net
